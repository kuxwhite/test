## 3. Решения пользователя (не нарушать)

- Самолёт как объект в небе убран совсем. Только «вид из окна».
- Салон и номер светлые, с голубым оттенком. Упор на вид в окне: он самый яркий и насыщенный.
- Никаких тёмных обводок и «грязных» градиентов. Спокойная, дорогая картинка.
- Фон не должен трястись. Движение деликатное.
- Вкладка Impression пока может показывать сцену Hotels (или оставить последнюю выбранную).

## 4. Переход между вкладками (главное)

Идея: окно одно, оно перетекает из иллюминатора в окно отеля.
1. Обе картинки лежат друг на друге в выровненных позициях (таблица выше).
2. При смене вкладки за 500–650 мс:
   - кроссфейд картинок (`opacity`), уходящая чуть масштабируется (0.98 → 1.02), приходящая наоборот;
   - короткий blur 0 → 6 px → 0 в середине перехода, чтобы форма рамки не «двоилась»;
   - кривая `cubic-bezier(0.32, 0.72, 0, 1)`; переход прерываемый (быстрый двойной тап по вкладкам не ломает анимацию).
3. Вариант посильнее (если хватит времени): маска-проём `clip-path` или SVG-маска из скруглённого прямоугольника, которая меняет размер с 106×162 на 205×190. Вид внутри меняется раньше, рамка позже.
4. Анимировать только `transform`, `opacity`, `filter` (композитные свойства). Никакого layout на каждом кадре.

## 5. Оживление сцен

Чтобы облака и вид двигались отдельно от рамки, нужны слои: интерьер с прозрачным проёмом и вид отдельно.
- **Быстрый путь без новых картинок:** вырезать проём маской (скруглённый прямоугольник по замерам выше), под ним — тот же кусок картинки, чуть увеличенный (110%), и двигать его параллаксом. Облака за иллюминатором — медленный горизонтальный дрейф дублированного слоя вида с бесшовной петлёй 20–30 с.
- **Лучше:** пользователь может догенерировать в ChatGPT вариант каждой картинки с проёмом, залитым #00FF00, и «вид отдельно». Тогда маска точная.
- **Параллакс:** вид смещается на ±8 px от наклона телефона (DeviceOrientation, разрешение на iOS запрашивать по первому тапу по шапке) и от перетаскивания пальцем по шапке. Пружина, без резких рывков. Интерьер стоит.
- **Занавеска в Hotels:** едва заметное покачивание, 4–6 с, `ease-in-out`.
- `prefers-reduced-motion`: без дрейфа и параллакса, только кроссфейд.
- Не обновлять React-state каждый кадр: писать `transform` через ref или CSS-переменные на самом элементе (не на родителе).

## 7. Ссылка для iPhone

Наклон телефона (DeviceOrientation) на iOS работает только по HTTPS и после тапа-разрешения. Варианты:
- `npx vercel --prod` (или Netlify, Cloudflare Pages): постоянная HTTPS-ссылка. `vite.config.js` уже с `base: './'`.
- Быстро, из той же Wi-Fi-сети: `@vitejs/plugin-basic-ssl` + `vite --host` → `https://<IP>:5173`, в Safari «посетить сайт» на самоподписанном сертификате.
- Туннель: `npx cloudflared tunnel --url http://localhost:5173`.

Для «как приложение»: в Safari «На экран „Домой“». Мета `apple-mobile-web-app-capable` и `viewport-fit=cover` уже стоят, статус-бар ляжет поверх шапки как в макете.
