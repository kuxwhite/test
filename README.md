# Экран поиска: «вид из окна»

React + Vite прототип по Figma (`6zX9IefdtemGiLH7nfVJqa`, экран 71:1738, идея шапки 89:1029).
Полное ТЗ — в [HANDOFF.md](HANDOFF.md).

```bash
npm install
npm run dev
```

## Шапка

`src/WindowScene.jsx` — сцена в шапке:

- **Flights** — иллюминатор, **Hotels** и **Impression** — окно отеля.
- Смена вкладки: кроссфейд + лёгкий масштаб + короткий blur, 600 мс, `cubic-bezier(0.32, 0.72, 0, 1)`; прерывается без рывков.
- Облака за иллюминатором медленно плывут (две копии вида сменяют друг друга, без швов).
- Вид в окне смещается от наклона телефона и от пальца (пружина, до ±8 px), рама стоит.
  На iPhone доступ к наклону запрашивается по первому тапу по шапке и работает только по HTTPS.
- Занавеска в отеле едва заметно покачивается.
- `prefers-reduced-motion`: только кроссфейд.

Маски проёмов и занавески (`public/scenes/fx/`) построены из иллюстраций скриптом:

```bash
python3 scripts/make-scene-fx.py
```

Сами иллюстрации в `public/scenes/` не меняются.
