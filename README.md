## Компоненты

`src/components/` — компоненты со страницы Figma «Components» (103:1127), со всеми состояниями;
стили в `components.css` только через переменные из `src/tokens.css`.

| Компонент | Состояния |
|---|---|
| `SearchTab` | выбран / не выбран × обычный / нажат |
| `SearchField`, `RouteFields` | заполнено / плейсхолдер / фокус (синяя подпись, каретка 2×22) |
| `IconField`, `HotelFields` | плейсхолдер / заполнено / фокус (синяя иконка и каретка) |
| `SearchButton` | обычная / нажата / загрузка (спиннер) / неактивна |
| `ShortcutTile` | обычная / нажата |
| `PlanCard` | обычная / нажата |
| `GlassButton` | аватар / избранное / избранное активно (пружинный «поп») |

Табы переключают экран: Flights — поля маршрута, «Search», плитки и «Plans for autumn»;
Hotels — поля отеля, «Search hotels», карточки без заголовка. Высота карточки поиска
анимируется, поля меняются со сдвигом и затуханием. Для Tours в Figma экрана нет,
пока он повторяет Flights.

Иконки выгружены из Figma как SVG, цвета подставлены токенами.

## Шапка: живые сцены

`src/WindowScene.jsx` + `src/scenes/` — синемаграф на WebGL2 (свой fragment shader, один
canvas на сцену, devicePixelRatio ≤ 2, на каждом кадре меняются только uniforms):

- **Flights** (иллюминатор): облака плывут слева направо (нос самолёта слева) тремя слоями —
  дальний, средний и ближние процедурные клочья; самолёт покачивается, изредка турбулентность;
  из угла стекла бьют мягкие лучи, по стеклу пробегает блик, на стене дышит тёплое пятно.
  За стеклом пролетают другие самолёты с инверсионным следом и стайки птиц.
- **Hotels** (окно): один общий ветер `gust(t)` качает створки (вокруг петель), штору
  (верх закреплён, волна к низу), растение и деревья в городе; облака плывут, вода течёт
  и блестит. По прибрежной дороге ездят машины, по берегу ходят люди, по морю идут
  парусники, по небу пролетают чайки.
- «Актёры» (`src/scenes/actors.js`) — маленькие SVG в слоях с маской области, поэтому
  они проходят за рамами.
- Наклон телефона и палец: вид за окном смещается на ±4 px поверх анимации.
- Смена вкладки: кроссфейд + масштаб + короткий blur, обе сцены живые во время перехода.
- Скролл: шапка закреплена (`sticky`), контент наезжает; сцена уходит вверх в 0.3× скролла,
  масштаб до 1.06, затемнение до 15% (`animation-timeline: scroll()`, иначе rAF).
  Когда шапка закрыта или вкладка скрыта — сцена на паузе.
- `prefers-reduced-motion`: иллюминатор статичен; в отеле только медленное покачивание.

Все скорости, амплитуды и периоды — в `src/scenes/config.js`.

Маски и бесшовные полосы облаков строит скрипт (картинки сцен не меняются):

```bash
node tools/make-masks.mjs
```

Превью масок: `reference/masks-preview-*.png`. Проверочные кадры (нужен `npm run dev`):

```bash
node tools/motion-check.cjs
```
