# Экран поиска: «вид из окна»

React + Vite прототип по Figma (`6zX9IefdtemGiLH7nfVJqa`). Источник правды — секция
«Handoff → code» (110:755): Flights 106:283, Hotels 110:569. Полное ТЗ — в [HANDOFF.md](HANDOFF.md).

```bash
npm install
npm run dev
```

## Компоненты

`src/components/` — компоненты со страницы Figma «Components» (103:1127), со всеми состояниями;
стили в `components.css` только через переменные из `src/tokens.css`.

| Компонент | Состояния |
|---|---|
| `SearchTab` | выбран / не выбран × обычный / нажат |
| `SearchField`, `RouteFields` | заполнено / плейсхолдер / фокус (синяя подпись, каретка 2×22) |
| `IconField`, `HotelFields` | плейсхолдер / заполнено / фокус (синяя иконка и каретка) |
| `SearchButton` | обычная / нажата / загрузка (спиннер) / неактивна |
| `ShortcutTile` | обычная / нажата |
| `PlanCard` | обычная / нажата |
| `GlassButton` | аватар / избранное / избранное активно (пружинный «поп») |

Табы переключают экран: Flights — поля маршрута, «Search», плитки и «Plans for autumn»;
Hotels — поля отеля, «Search hotels», карточки без заголовка. Высота карточки поиска
анимируется, поля меняются со сдвигом и затуханием. Для Tours в Figma экрана нет,
пока он повторяет Flights.

Иконки выгружены из Figma как SVG, цвета подставлены токенами.

## Шапка

`src/WindowScene.jsx` — сцена в шапке:

- **Flights** — иллюминатор, **Hotels** и **Impression** — окно отеля.
- Смена вкладки: кроссфейд + лёгкий масштаб + короткий blur, 600 мс, `cubic-bezier(0.32, 0.72, 0, 1)`; прерывается без рывков.
- Облака за иллюминатором медленно плывут (две копии вида сменяют друг друга, без швов).
- Вид в окне смещается от наклона телефона и от пальца (пружина, до ±8 px), рама стоит.
  На iPhone доступ к наклону запрашивается по первому тапу по шапке и работает только по HTTPS.
- Занавеска в отеле едва заметно покачивается.
- `prefers-reduced-motion`: только кроссфейд.

Маски проёмов и занавески (`public/scenes/fx/`) построены из иллюстраций скриптом:

```bash
python3 scripts/make-scene-fx.py
```

Сами иллюстрации в `public/scenes/` не меняются.
